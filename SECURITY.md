# Politique de sécurité

## Versions supportées

| Version | Supportée |
|---------|-----------|
| 1.x     | ✅ Oui    |

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité de sécurité, merci de ne pas ouvrir d'issue publique. Contactez directement le mainteneur du projet par un moyen privé.

Nous nous engageons à accuser réception de votre signalement sous 72 heures et à vous tenir informé de l'avancement de la correction.

## Bonnes pratiques pour les utilisateurs

- N'installez la carte que depuis des sources de confiance (ce dépôt GitHub ou HACS).
- Vérifiez toujours la signature et l'intégrité des fichiers téléchargés.
- Maintenez votre instance Home Assistant à jour.
